┌──────────────────────────────────────────────────────────────────────────────┐
│                        🔑 5 PATRONES IMPLEMENTADOS                           │
└──────────────────────────────────────────────────────────────────────────────┘

  1️⃣  FAÇADE PATTERN
      └─ Servicio centralizado que orquesta todo
         ✅ facade.loadUsers()
         ✅ facade.createUser(data)
         ✅ facade.updateUser(id, data)
         ✅ facade.deleteUser(id)
      📂 Ubicación: shared/services/settings-facade.service.ts

  2️⃣  SIGNALS (Reactividad Angular 17+)
      └─ Estado reactivo sin RxJS subscriptions
         ✅ users = this.facade.users
         ✅ {{ users().length }}  (Actualiza automáticamente)
      📂 Ubicación: Todas las signals

  3️⃣  COMPONENTES GENÉRICOS
      └─ Una tabla/modal para todo tipo de datos
         ✅ <app-generic-table [columns]="c" [data]="d" />
         ✅ <app-modal-editor [isOpen]="o" />
      📂 Ubicación: shared/components/

  4️⃣  SERVICIOS ESPECIALIZADOS
      └─ Cada submodulo tiene su servicio
         ✅ UsersService (API usuarios)
         ✅ PoliciesService (API políticas)
         ✅ CaseStatusesService (API estados)
      📂 Ubicación: modules/{name}/services/

  5️⃣  SEPARACIÓN DE RESPONSABILIDADES
      └─ Cada capa tiene su función
         ✅ Models → Tipos (sin lógica)
         ✅ Services → HTTP y transformación
         ✅ Façade → Orquestación
         ✅ Components → UI e interacción
